# wavemotion.live

Public website for **Wavemotion**, served by GitHub Pages at https://wavemotion.live.

The Wavemotion app runs on Cloudflare Workers. App paths (`/d/…` Living Destinations, `/connect/…` client links, `/go/…` link clicks, `/auth/…`, `/privacy`, `/terms`) are carried to the app with the same path by `404.html`. Change the app address in `app.js` and `404.html` when it moves.
